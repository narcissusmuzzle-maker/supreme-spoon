U613 «Циферблат» для Amazfit Bip Max — версия 0.1.0 (первый экран)

ЧТО ЭТО
Отдельный проект (циферблат, не приложение). Чёрный экран без часов, разделён примерно пополам:
  Верхняя половина — две полоски статистики без подписей, у каждой три сегмента: месяц / неделя / день (слева направо).
    Верхняя — слова. Цвета те же, что у поля слов на телефоне (красный -> оранжевый -> жёлтый -> салатовый -> зелёный), сегмента «всего» нет.
    Сейчас это ЗАГЛУШКА: настоящих данных у циферблата пока нет, цвета взяты из выдуманных долей нормы (WORDS_STUB в watchface/index.js).
    Нижняя — серая заглушка.
  Нижняя половина — три большие кнопки 🥗 🩸 🧩.
    🩸 открывает приложение «Таймер» (U613, то, что уже стоит на часах). 🥗 и 🧩 пока ничего не делают.
Приложения «Таймер» (U613-timer-v15) и LuvU613 (телефон) этот проект не трогает и не меняет.

КАК УСТАНОВИТЬ (так же, как приложение часов)
1. Создайте НОВЫЙ репозиторий на GitHub и загрузите в него ВСЁ из этой папки (Add file -> Upload files). Скрытых папок в архиве нет.
   Файл сборки: Add file -> Create new file, имя .github/workflows/build.yml, внутрь текст из файла build.yml.
2. Settings -> Pages: включите публикацию из ветки gh-pages (как делали раньше). Вкладка Actions: дождаться зелёной галочки
   (если первый запуск прошёл до включения Pages — запустите ещё раз: Actions -> Run workflow).
3. QR-код "square-432x514" -> в Zepp: Профиль -> часы -> Режим разработчика -> сканировать.
4. Циферблат появится в списке циферблатов часов (долгое нажатие на текущий циферблат -> листать в конец списка) —
   выберите его.

ЧТО ПРОВЕРИТЬ ПЕРВЫМ ДЕЛОМ
- Открывается ли «Таймер» по нажатию на 🩸. Если нет — под полосками, на границе половин, появится короткая красная надпись
  с причиной; пришлите её текст.
- Не съехала ли раскладка вправо/влево (см. ниже, AREA_X).

ГДЕ ЧТО МЕНЯТЬ
shared/layout.js:
  AREA_X, AREA_W      — горизонтальная полоса, в которой стоят полоски и кнопки (8 и 380: та же сетка, что на главном экране приложения «Таймер»).
                        Если на циферблате всё смещено — меняйте AREA_X (центр экрана для 432 px: AREA_X = 26).
  STRIP_H, STRIP_GAP  — высота полоски и расстояние между ними.
  SEG_GAP             — чёрный зазор между сегментами (3). 0 — сплошная полоска, как на телефоне.
  STRIPS_DY, BTN_DY   — сдвиг блока полосок / ряда кнопок вверх (минус) или вниз (плюс).
shared/colors.js       — палитра (как в приложении на телефоне) и цвет серой заглушки (GRAY).
watchface/index.js     — WORDS_STUB (цвета верхней полоски), SECOND_STUB (нижняя), TIMER_APP_ID / TIMER_APP_URL (что открывает 🩸).

ПОЧЕМУ СЛОВА ПОКА ЗАГЛУШКА
Телефон сейчас отдаёт часам только очередь занятий и подарки; статистики слов в его ответе нет, а без правки приложения на телефоне
её не получить. Когда будете обновлять телефон, это следующий шаг.

ТЕСТЫ (необязательно): npm test — проверяют палитру, раскладку и прогон циферблата на заглушках API часов.
